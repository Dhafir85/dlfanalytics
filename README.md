# DLF Analytics

Welcome to the repository for **DLF Analytics**, a modern developer portfolio and analytics website.

## Features
- **⚡ Fast Performance**: Built using Hugo and Tailwind CSS.
- **🧠 Rich Layouts**: Structured templates for projects, blog posts, and bio.
- **📱 Responsive Design**: Fully responsive across mobile, tablet, and desktop devices.

## Running Locally

To run the development server locally, open your terminal and run:

```bash
hugo server --disableFastRender
```

Then visit **http://localhost:1313** in your browser.

## Deployment

The website can be built for production using:

```bash
hugo --minify
```
